read me :# 🦷 SmileCare - Dental Clinic Website

A responsive multi-page dental clinic website built using HTML, CSS, JavaScript, and Bootstrap.

## 📌 Project Overview

SmileCare is a front-end web application designed for a dental clinic. It provides patients with information about the clinic, doctors, services, articles, appointments, and contact details.

---

## ✨ Features

- Responsive Design
- Reusable Navbar & Footer Components
- Home Page
- About Us Page
- Services Page
- Doctors Page
- Doctor Profile Page
- Articles Page
- Medical Store Page
- Appointment Page
- Contact Us Page
- Login & Register Pages
- Patient Dashboard

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Bootstrap 5
- Font Awesome
- JSON
- Local Storage
- Fetch API
